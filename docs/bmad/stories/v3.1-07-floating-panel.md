# Story v3.1-07 — Floating panel UI + Alpine component

**Sub-project:** v3.1 Real-time Terminal
**Status:** Ready
**Depends on:** v3.1-05 (API), v3.1-06 (frontend bundle)
**Effort:** M (4–6 hours)
**Branch:** `story/v3.1-07-floating-panel`

## Story

Build the floating terminal panel that lives at the bottom of every
panel page, hooked to the active project. Replaces the in-File-Manager
terminal panel with a global, always-available, real-time-streaming
component.

## Acceptance Criteria

1. New blade partial `resources/views/panel/_terminal.blade.php` rendered once at the end of `layout.blade.php`. Includes:
   - Sidebar toggle button (visible from any page) with status indicator (`◌` idle / `⚡` running / `✓` done)
   - Floating panel container, hidden by default, shown when toggle clicked
   - Header: project name (italic Fraunces), cwd display, controls (`× _ ⤢`)
   - Body: xterm canvas (mounted via `x-ref`)
   - Footer: prompt + input + `[Run]` `[⏹ Stop]` buttons
2. `hermesTerminal()` Alpine data fully implemented per design Section 5 state shape (`open, expanded, minimized, project, cwd, display, status, sessionId, history, historyIndex, inputBuffer, term, fitAddon, searchAddon, echoChannel`).
3. On page load:
   - Read active project from `<meta name="hermes-active-project" content="...">` injected by `layout.blade.php`
   - Call `GET /panel/api/terminal/state?project=<slug>` to discover any active session
   - If active: `GET /panel/api/terminal/{session_id}/replay` and write chunks instantly to xterm
   - Subscribe to `private-terminal.{project_slug}` channel
4. `run()` action:
   - `POST /panel/api/terminal/execute {project, command}` — when in auth-enforced mode
   - `POST /panel/api/terminal/execute-sync {project, command}` — when in bypass mode (detected via meta tag or initial `/state` response)
   - On 409: show toast "Session already running. Stop or wait."
   - On 422: show toast with rejection reason
5. `stop()` action: `POST /panel/api/terminal/{session_id}/stop`. Disable Stop button while exiting.
6. `reset()` action: `POST /panel/api/terminal/reset` — kills active session and clears xterm screen.
7. Up/Down arrow in input traverses history (per-project, fetched from `/state`); Ctrl+L clears xterm; Ctrl+F opens xterm-addon-search; URL clicks open in new tab.
8. Welcome banner shows once per session open: project name, cwd, hint about shortcuts.
9. Sidebar project switcher dispatches a custom event `hermes:project-changed`. The terminal Alpine listens, swaps subscription, clears xterm, fetches new state + replay.
10. Panel persists `open`/`expanded` state across navigation via `localStorage` key `hermes:terminal:open` and `hermes:terminal:expanded`.
11. Existing terminal panel inside `resources/views/panel/files.blade.php` is **removed** (the floating one supersedes it). All references in JS and blade cleaned up.
12. Visual style consistent with existing design system: `--ink`, `--paper`, `--copper`, font-mono labels, fade-up animation on open.
13. Mobile (< 768 px): panel becomes fullscreen overlay instead of bottom-anchored. Toggle button moves to mobile bottom nav (replaces a slot, e.g. `ε Projects`).
14. `./vendor/bin/pint` clean. Manual smoke test green.

## Smoke Check

1. Login to panel, switch to a Laravel test project
2. Click sidebar terminal toggle → floating panel appears with welcome banner
3. Type `npm install --dry-run` (or any safe command), Enter
4. Output streams in real time with ANSI colors preserved
5. Click `Stop` mid-run → command terminates, exit chunk appears
6. Refresh page mid-stream → panel reappears, replays buffer, continues subscribing
7. Switch project in sidebar → terminal swaps to new project, new history visible
8. Up arrow → previous command appears in input
9. Ctrl+F → xterm search overlay opens, find string works
