# Story v3.1-08 — Idle timeout default 15min + polish + E2E

**Sub-project:** v3.1 Real-time Terminal
**Status:** Done
**Depends on:** v3.1-07 (floating panel)
**Effort:** S–M (2–4 hours)
**Branch:** worked directly on `feature/v3.1-realtime-terminal`

## Story

Lower the idle timeout default to 15 minutes (replacing the 120-minute
session lifetime), add Playwright E2E tests for the terminal flow, and
polish loose ends before merging the v3.1 sub-project.

## Acceptance Criteria

1. `config/panel.php` `session_lifetime` default lowered from 120 → 15.
2. `.env.example` `PANEL_SESSION_LIFETIME=15` (was 120). Comment above explains: "Idle timeout in minutes. Refreshes on every authenticated HTTP request to the panel. WebSocket messages do not refresh this timer."
3. README `## Configuration` table reflects new default `15` for `PANEL_SESSION_LIFETIME` and notes the behavior (HTTP refreshes, WS does not).
4. README "Upgrade notes" section added under `## Authentication & Deployment Security`:
   > Existing instances upgrading from earlier versions: the default `PANEL_SESSION_LIFETIME` is now 15 minutes (was 120). Set the value explicitly in your `.env` if you want the old behavior.
5. Playwright E2E tests at `tests/e2e/`:
   - `terminal-stream.spec.ts` — open floating terminal, run `echo hello && sleep 1 && echo world`, assert progressive output, assert exit chunk, assert command in history (up arrow).
   - `terminal-reconnect.spec.ts` — run a 10-second loop command, observe initial output, reload page mid-execution, assert replay + continued streaming, assert final exit reached.
6. `composer.json` adds script `test:e2e` running playwright (assumes `playwright` is already a dependency).
7. Polish items resolved:
   - Loading state on Run button (spinner while waiting for session_id)
   - Toast variants for 409 (warning) and 422 (error) with explicit copy
   - Empty state in xterm when freshly opened (welcome banner only)
   - `xterm-addon-fit` reactive on window resize and on panel expand/minimize
   - Disabled state for Run when input is empty
8. `agents.md` section 14 updated with v3.1 status: "v3.1 real-time terminal — DONE".
9. `docs/bmad/bmm-workflow-status.yaml` updated:
   - `phase_4_implementation.stories_completed` += 8
   - new entry in `workflow_log` for v3.1 sprint complete
   - clear `pending_decisions[REVERB-AUDIT]` (resolved by story 05)
   - clear `pending_decisions[MED-5]` (resolved by story 02)
10. All previous stories' tests still green: `php artisan test`.
11. `./vendor/bin/pint` clean.
