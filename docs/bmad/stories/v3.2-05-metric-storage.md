# Story v3.2-05 — MetricStorage SQLite schema + WAL + aggregate/prune

**Sub-project:** v3.2 VPS Monitoring
**Status:** Done
**Depends on:** v3.2-02 (Snapshot DTO)
**Effort:** M (3–5 hours)

## Story

Build the durable storage layer. Dedicated SQLite at
`storage/monitoring.sqlite` so panel-DB outages don't kill monitoring,
and vice versa. Schema bootstrap runs idempotently on first tick-loop
boot — no migration in panel default DB.

## Acceptance Criteria

1. `config/database.php` adds `monitoring` connection:
   ```php
   'monitoring' => [
       'driver' => 'sqlite',
       'database' => storage_path('monitoring.sqlite'),
       'foreign_key_constraints' => false,
       'busy_timeout' => 5000,
       'journal_mode' => 'WAL',
       'synchronous' => 'NORMAL',
   ],
   ```
2. `App\Services\Monitoring\MetricStorage` class:
   - Constructor accepts `ConnectionInterface` (resolved from `DB::connection('monitoring')`)
   - `bootstrap(): void` — creates tables + indexes if not exist (idempotent), called on tick-loop boot
   - `recordSample(Snapshot $snapshot): void` — flatten numeric metrics → `samples_raw`, write JSON to `latest_snapshot`, atomic transaction
   - `aggregateMinute(int $minuteBoundaryTs): void` — compute avg/min/max from preceding 60 s of raw samples
   - `prune(int $now): void` — delete `samples_raw` < (now - 1h) and `samples_1m` < (now - 24h); run `PRAGMA wal_checkpoint(TRUNCATE)` after
   - `latestSnapshot(): ?array` — single-row read for HTTP /snapshot
   - `rangeRaw(string $metric, int $from, int $to): array` — values keyed by ts
   - `rangeMinute(string $metric, int $from, int $to): array` — avg/min/max rows keyed by ts
3. Schema:
   ```sql
   CREATE TABLE IF NOT EXISTS samples_raw (
       ts INTEGER NOT NULL, metric TEXT NOT NULL, value REAL NOT NULL,
       PRIMARY KEY (ts, metric)
   ) WITHOUT ROWID;
   CREATE INDEX IF NOT EXISTS idx_samples_raw_ts ON samples_raw(ts);

   CREATE TABLE IF NOT EXISTS samples_1m (
       ts INTEGER NOT NULL, metric TEXT NOT NULL, avg REAL, min REAL, max REAL,
       PRIMARY KEY (ts, metric)
   ) WITHOUT ROWID;
   CREATE INDEX IF NOT EXISTS idx_samples_1m_ts ON samples_1m(ts);

   CREATE TABLE IF NOT EXISTS latest_snapshot (
       ts INTEGER NOT NULL PRIMARY KEY, payload TEXT NOT NULL
   ) WITHOUT ROWID;
   ```
4. Constants documented:
   ```php
   public const RAW_RETENTION_SECONDS = 3600;
   public const AGG_RETENTION_SECONDS = 86_400;
   ```
5. Bound as singleton in `AppServiceProvider::register()`:
   ```php
   $this->app->singleton(MetricStorage::class, fn ($app) => new MetricStorage(
       $app->make('db')->connection('monitoring')
   ));
   ```
6. Unit tests in `tests/Unit/Services/Monitoring/MetricStorageTest.php`:
   - `bootstrap` creates all 3 tables + indexes (idempotent on second call)
   - `recordSample` flattens cpu/memory/disk metrics correctly into samples_raw rows
   - `recordSample` updates `latest_snapshot` atomically
   - `aggregateMinute` computes avg/min/max from 12 raw rows over 60s window
   - `prune` removes only rows past retention boundary
   - `rangeRaw` returns ordered, keyed results
   - `rangeMinute` returns avg/min/max
   - Tests run against `:memory:` SQLite by overriding the connection in setUp
7. `./vendor/bin/pint` clean.
