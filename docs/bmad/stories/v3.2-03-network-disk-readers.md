# Story v3.2-03 — DiskUsage/DiskIo/Network/Connection readers

**Sub-project:** v3.2 VPS Monitoring
**Status:** Ready
**Depends on:** v3.2-02 (Reader interface + base readers)
**Effort:** M (3–5 hours)

## Story

Add the four delta-aware / shell-based readers covering disk usage,
disk I/O, network throughput, and TCP connection count. These are the
metrics that show up most often in "is my server unhealthy right now?"
diagnostics.

## Acceptance Criteria

1. `App\Services\Monitoring\Readers\DiskUsageReader`:
   - Returns `[{mount, fs, total_bytes, used_bytes, free_bytes, used_pct}]`
   - Shells out to `df -P --output=source,target,fstype,size,used,avail`
   - Skips pseudo filesystems (`tmpfs`, `devtmpfs`, `proc`, `sysfs`, `cgroup*`, `overlay`)
2. `App\Services\Monitoring\Readers\DiskIoReader`:
   - Returns `{read_bytes_per_sec, write_bytes_per_sec, per_device: [{device, read_bytes_per_sec, write_bytes_per_sec}]}`
   - Reads `/proc/diskstats` (delta from cached previous reading)
   - First-sample handling: returns `'first_sample' => true` with raw counters
   - Skips loop devices (`loop*`) and ram devices (`ram*`)
3. `App\Services\Monitoring\Readers\NetworkReader`:
   - Returns `[{iface, rx_bytes_per_sec, tx_bytes_per_sec, rx_errs, tx_errs}]`
   - Reads `/proc/net/dev` (delta)
   - Skips loopback (`lo`) and inactive interfaces (rx + tx == 0 across two consecutive reads)
4. `App\Services\Monitoring\Readers\ConnectionReader`:
   - Returns `{tcp_established: int}`
   - Reads `/proc/net/tcp` and `/proc/net/tcp6`, counts state == `01` (ESTABLISHED)
5. All four readers registered with `monitoring.readers` service tag.
6. Unit tests:
   - `DiskUsageReaderTest` — fixture df output, asserts pseudo-fs filter, percentage rounding
   - `DiskIoReaderTest` — first-sample + second-sample fixtures, delta math, loop device filter
   - `NetworkReaderTest` — first-sample + second-sample fixtures, lo filter, inactive iface filter
   - `ConnectionReaderTest` — fixture `/proc/net/tcp` + `tcp6`, asserts state filter
7. `./vendor/bin/pint` clean.
