# Story v3.2-04 — Process/Service/Port readers + whitelist patterns

**Sub-project:** v3.2 VPS Monitoring
**Status:** Done
**Depends on:** v3.2-02 (Reader interface)
**Effort:** M (3–5 hours)

## Story

Add the three "discrete state" readers: top processes, service health
(systemctl + pgrep fallback), and listening ports. These power the
service table, process top, and port list sections of the Monitoring
tab.

## Acceptance Criteria

1. `App\Services\Monitoring\Readers\ProcessReader`:
   - Returns `[{pid, name, cmd, cpu_pct, rss_kb}]`
   - Top 5 by CPU + top 5 by RSS, deduped → max 10 rows
   - Iterates `/proc/[pid]/stat` (utime + stime) and `/proc/[pid]/status` (VmRSS)
   - Caches per-PID cumulative ticks for delta computation; first sample returns null cpu_pct
2. `App\Services\Monitoring\Readers\ServiceReader`:
   - Returns `[{unit, status: 'active'|'inactive'|'failed'|'unknown', detection: 'systemd'|'pgrep'}]`
   - Discovers units via `systemctl list-units --type=service --state=running,loaded` matched against `config('panel.monitoring.service_patterns')`
   - Caches discovered list with `hermes:monitoring:services:units` key, TTL 60 s
   - Per-unit status via `systemctl is-active <unit>`
   - Falls back to `pgrep -x <process_name>` when systemctl unavailable; status = 'active' if any matching pid, 'inactive' otherwise; detection = 'pgrep'
3. `App\Services\Monitoring\Readers\PortReader`:
   - Returns `[{port, proto, address, pid, process_name}]`
   - Listening only (TCP `LISTEN` state, UDP all)
   - Shells out to `ss -tlnp` then `ss -ulnp`; falls back to `netstat -tlnp` + `netstat -ulnp` when ss unavailable
   - Parses `users:(("nginx",pid=1234,fd=6))` style output
4. `config/panel.php` adds default service patterns:
   ```php
   'monitoring' => [
       'service_patterns' => [
           'nginx*', 'apache2*', 'caddy*', 'traefik*',
           'mysql*', 'mariadb*', 'postgres*', 'postgresql*',
           'redis*', 'memcached*',
           'php-fpm*', 'php*-fpm*',
           'docker', 'containerd', 'podman',
       ],
   ],
   ```
5. All three readers registered with `monitoring.readers` service tag.
6. Unit tests:
   - `ProcessReaderTest` — fixture `/proc/[pid]/{stat,status}` for 3 fake pids; asserts top-N + dedup logic
   - `ServiceReaderTest` — `discoverUnits()` filters whitelist; cache populated with 60s TTL; pgrep fallback when systemctl returns non-zero
   - `PortReaderTest` — ss fixture parses correctly, netstat fallback when ss unavailable
7. `./vendor/bin/pint` clean.
