# Story v3.2-02 — Reader interface + Cpu/Memory/Uptime readers

**Sub-project:** v3.2 VPS Monitoring
**Status:** Ready
**Depends on:** v3.2-01 (`ProcResolver`)
**Effort:** M (3–5 hours)

## Story

Establish the `Reader` interface, `Snapshot` value object, and the first
three readers (CPU, memory, uptime). Wire them up via tagged container
binding so subsequent stories just register more tags.

## Acceptance Criteria

1. New interface `App\Services\Monitoring\Reader` with `key(): string` and `read(ProcResolver $proc): array`.
2. New value object `App\Services\Monitoring\Snapshot` (read-only DTO):
   - Public properties: `int $ts`, `array $entries`, `array $errors`
   - `static fromArray(array $data): self`, `toArray(): array`, `get(string $key): ?array`
3. `App\Services\Monitoring\MetricCollector`:
   - Constructor accepts iterable of readers + ProcResolver
   - `sample(): Snapshot` invokes every reader, captures per-reader errors into `errors[]`, never throws
4. `App\Services\Monitoring\Readers\CpuReader`:
   - Returns `{loadavg: {1m, 5m, 15m}, cores: int, usage_pct_total: float, per_core: float[]}`
   - Reads `/proc/loadavg` and `/proc/stat`
   - Caches previous `/proc/stat` cumulative values via `hermes:monitoring:last:cpu`; first call returns `usage_pct_total: null` and adds `'first_sample' => true`
5. `App\Services\Monitoring\Readers\MemoryReader`:
   - Returns `{total_kb, used_kb, free_kb, available_kb, buffers_kb, cached_kb, swap_total_kb, swap_used_kb}`
   - Reads `/proc/meminfo`, gracefully handles missing fields (returns null, not throws)
6. `App\Services\Monitoring\Readers\UptimeReader`:
   - Returns `{boot_time_unix, uptime_seconds}`
   - Reads `/proc/uptime` and `/proc/stat` btime line
7. Service registration in `AppServiceProvider::register()`:
   - Tag `[CpuReader, MemoryReader, UptimeReader]` as `monitoring.readers`
   - Bind `MetricCollector` as singleton, resolves tagged readers
8. Unit tests in `tests/Unit/Services/Monitoring/`:
   - `MetricCollectorTest` — invokes registered readers; one reader throwing is captured in errors, others continue; ordering matches registration; empty iterable yields empty entries
   - `Readers/CpuReaderTest` — fixture `/proc/stat` + `/proc/loadavg` files in `tests/Fixtures/Monitoring/`; first call returns `first_sample: true`; second call computes delta correctly
   - `Readers/MemoryReaderTest` — fixture `/proc/meminfo` parses correctly; missing field returns null
   - `Readers/UptimeReaderTest` — fixture parses correctly
9. `./vendor/bin/pint` clean on touched files.
